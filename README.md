# My zsh config

The interactive configuration lives in a single `.zshrc`. `.zshenv` only
contains environment setup that must also run for non-interactive shells.

## Installation

```zsh
ln -s <THIS_REPO_PATH> ~/.config/zsh
ln -s <THIS_REPO_PATH>/.zshrc ~/.zshrc
```

If using Arch Linux, make sure to install `grml-zsh-config`
